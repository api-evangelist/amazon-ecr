GameLift now supports customizing Linux capabilities for containers (such as NET_RAW for custom networking or SYS_PTRACE for debugging) and inter-container discovery. The new ListContainersNetworkInfo() server SDK action retrieves container name, ID, local IP, and group type, available in server SDK 5.x for Go, C++, C#, and Unreal/Unity plugins.
