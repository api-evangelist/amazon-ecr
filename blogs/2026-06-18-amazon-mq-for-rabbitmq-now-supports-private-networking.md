Amazon MQ for RabbitMQ now supports private networking connectivity, letting brokers reach private resources without public exposure for RabbitMQ Federation, Shovel, and private LDAP/OAuth authentication. It uses VPC Lattice, AWS RAM, and PrivateLink infrastructure and is available wherever VPC Lattice operates.
