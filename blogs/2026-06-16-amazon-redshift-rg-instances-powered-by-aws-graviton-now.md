Redshift RG instances expand to Africa (Cape Town), Asia Pacific (Bangkok), and Mexico (Central). The Graviton-based RG instances deliver 4.2X better price-performance for data warehouse workloads, run 2.4x faster than RA3, and cost 30% less per vCPU, available as rg.xlarge and rg.4xlarge node types.
