title: "Amazon RDS for SQL Server increases the maximum size and provisioned performance of General Purpose (gp3) volumes"
url: "https://aws.amazon.com/about-aws/whats-new/2026/06/rds-sqlserver-increases-gp3-limits/"
date: "2026-06-18"
feed_url: "https://aws.amazon.com/about-aws/whats-new/recent/feed/"
---
RDS for SQL Server now supports gp3 volumes scaling to 64 TiB (4X the previous 16 TiB limit), up to 80,000 IOPS (5X the previous 16,000), and up to 2,000 MiB/s throughput (2X the previous 1,000). Users can configure up to three additional volumes per instance, reaching 256 TiB total, with no pricing changes.
