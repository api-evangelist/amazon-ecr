Secrets Manager offers a secret safety skill in the Agent Toolkit aws-core plugin that prevents secret value exposure to models by steering agents away from raw values and resolving references at execution time outside the agent process. Plaintext secrets never appear in model context, session logs, or agent memory, available for Claude Code, Codex, and Cursor.
