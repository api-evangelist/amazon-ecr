Oracle Database@AWS now supports Oracle Autonomous AI Database Serverless (ADB-S) on Exadata infrastructure with automatic patching and tuning, provisioned via AWS Console, CLI, or APIs. It supports four workload types (AI Transaction Processing, AI Lakehouse, AI JSON Database, Oracle APEX) with independent compute/storage scaling, Autonomous Data Guard, S3 backups, and cross-region disaster recovery.
