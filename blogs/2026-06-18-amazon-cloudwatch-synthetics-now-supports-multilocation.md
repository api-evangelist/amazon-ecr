CloudWatch Synthetics now supports multilocation canaries, letting developers and SREs run the same canary across multiple AWS Regions simultaneously instead of creating separate canaries per region. It consolidates run data, metrics, and artifacts in a primary region while replicating to additional regions, and existing canaries can be upgraded.
