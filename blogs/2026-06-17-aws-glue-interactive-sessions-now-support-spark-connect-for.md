AWS Glue Interactive Sessions now support Apache Spark Connect, enabling development from SageMaker Unified Studio, Jupyter, or VS Code. The thin client architecture decouples the client application from the Spark execution environment for ad hoc exploration and iterative debugging, with Spark UI and History Server tracking, in 13 AWS regions.
