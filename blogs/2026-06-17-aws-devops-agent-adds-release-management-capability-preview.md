DevOps Agent preview adds release management for reviewing code changes and running autonomous release testing. Release readiness review checks for drift from internal standards, dependency impacts, and access controls, while release testing generates and runs test plans for web and API applications. Available in US East (N. Virginia) at no additional cost during preview.
