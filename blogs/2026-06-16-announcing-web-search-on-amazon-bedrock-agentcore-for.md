Web Search on AgentCore enables agents to ground responses in current web knowledge while keeping data residency within a secured AWS environment, built on Amazon's search infrastructure combining a web index with structured knowledge graphs. It returns ranked excerpts, source URLs, titles, and publication dates, available in US East (N. Virginia).
