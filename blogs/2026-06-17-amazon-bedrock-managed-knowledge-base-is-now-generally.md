Bedrock Managed Knowledge Base, a fully managed RAG service, is now generally available with six native connectors (S3, SharePoint, Confluence, Google Drive, OneDrive, Web Crawler), automatic syncing, and managed vector storage. It offers hybrid search, document ranking, and agentic retrieval for multi-hop queries, integrating natively with AgentCore across 8 AWS regions.
