Security Agent's threat modeling (public preview) automatically generates threat models by analyzing design documents or source code, understanding architecture, data flows, and trust boundaries to produce contextually relevant mitigations across all six STRIDE categories. It integrates into Kiro and Claude Code at no additional cost during preview.
