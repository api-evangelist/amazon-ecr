AWS China (Ningxia) region now offers Ubuntu 24.04 LTS bundles for Amazon WorkSpaces Personal, providing updated Linux packages, toolchains, and security improvements with extended Canonical support. It offers a migration path for older Amazon Linux 2 WorkSpaces users and is available in the China (Ningxia) region only.
