Security Agent now supports Kiro and Claude Code for IDE-based security scans, with simulated validations executing findings in isolated environments to return evidence of how a vulnerability can be exploited. New integrations include GitLab.com, GitLab Self Managed, GitHub Enterprise, Bitbucket, and Confluence across all supported regions.
