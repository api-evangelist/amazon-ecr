Bedrock Guardrails introduces the InvokeGuardrailChecks API, a resourceless API enabling granular per-request safeguard control in agentic workflows with content filters, prompt attack detection, and PII filters returning numeric severity and confidence scores. It operates in detect-only mode and is available in 7 AWS regions.
