AgentCore policy now integrates Bedrock Guardrails to evaluate outputs of every authorized agent action and inputs of every call to a gateway target in real time, detecting prompt injection, harmful content, and data exposure. Evaluation occurs at the gateway perimeter outside agent code for consistent enforcement regardless of autonomy level.
