Glue Data Catalog preview adds business context and semantic search, letting users enrich catalog tables with glossary terms and custom metadata and find data by semantic meaning via the Glue Search API. MCP-compatible agents including Claude Code work with the aws-data-analytics plugin, available in US East, US West, and Europe (Ireland).
